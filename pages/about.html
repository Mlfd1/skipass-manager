Дипломная работа

О проекте

Техническая и концептуальная база системы управления продажей абонементов и ски-пассов.

Цели и задачи

Что решает система

Основные проблемы горнолыжных курортов Кыргызстана, которые устраняет разрабатываемая информационная система.

1

Устранение ручного учёта

Переход от бумажных журналов и ручных кассовых операций к полностью цифровому документообороту.

2

Автоматизация продаж

Онлайн-продажа 24/7 без участия кассира, интеграция с платёжными системами (Visa, MasterCard, MBanking).

3

Контроль доступа

Замена бумажных билетов на RFID/NFC карты с мгновенной валидацией на турникетах подъёмников.

4

Аналитика для управления

Предоставление руководству данных о выручке, посещаемости и загрузке трасс в реальном времени.

5

Повышение лояльности клиентов

Личный кабинет, бонусная программа и онлайн-сервис повышают удовлетворённость и повторные визиты.

Архитектура

Компоненты системы

Трёхуровневая архитектура: клиентский уровень, серверная логика, база данных.

Веб-приложение

React SPA для клиентов (покупка, личный кабинет) и для администраторов (управление, отчёты).

Backend API

Django REST Framework, обрабатывает запросы, бизнес-логику, интеграцию с оборудованием.

База данных

PostgreSQL — хранение клиентов, транзакций, пропусков, логов валидации.

Турникетный контроллер

Микроконтроллер с RFID-считывателем, подключён к серверу через TCP/IP.

Платёжный шлюз

Интеграция с банковскими API Кыргызстана (MBANK, Optima Pay, Visa/MC).

Модуль аналитики

Агрегация данных, построение отчётов, экспорт в Excel/PDF для руководства.
